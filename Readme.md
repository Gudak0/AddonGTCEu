# Gregious Maximus
An addon for GTCEu that adds tiers higher than UV. It also adds some new machines aswell.
This mod was intended for the LDS Craft modpack but are here for anyone to use.
Recipes in the mod will most likely not have recipes, as it was intended primarily for modpacks, but I may add some recipes for stuff so that it can be used alongside regular GTCEu

## What about Gregicallity Science?
I started this mod before I saw it existed. I'll still work on this addon mostly since it's for a modpack I was working on. However, I will NOT be implementing features from Gregicallity Science into this mod.
